# eval/runs/

Una carpeta por corrida, `AAAA-MM-DD_HHMM_<pipeline>/` (la crea `src/main.py`;
ignoradas por git):

| Archivo | Contenido |
|---|---|
| `submission.jsonl` | respuestas en el esquema oficial |
| `report.json` | salida de `scripts/evaluate.py` |
| `traces.jsonl` | un `Trace` por pregunta (subconsultas, pasajes, veredictos, tiempos) |
| `config.yaml` | copia de la config fusionada usada |
| `corrida.json` | split, ids, commit, inicio/fin; `terminada` al completar |
| `validacion.json` | problemas de `src/submission/validate.py` |

```bash
python -m src.main --config configs/baseline.yaml --split sample          # escribe también report.json
python -m src.main --config configs/baseline.yaml --split sample --reanudar   # si se cayó
python -m src.submission.validate eval/runs/<corrida>/submission.jsonl --split sample
python eval/compare.py eval/runs/
```
